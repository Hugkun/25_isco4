## results_gemini-{gemini_version}.xslx

### 目的
Geminiモデルごとの性能評価のログの保存。

### 保存ディレクトリ
`<project_root>/outputs/external/gemini/`

### 作成元
`<project_root>/python/external/gemini/evaluate_gemini_{gemini_version}.py`

### 使用先
`<project_root>/python/tools/visualize.py`

### 構造

| カラム名 | 説明 |
|------|-----------|
| question | 質問文。 |
| context | RAGによって検索された文脈。 |
| llm.execution_time | RAGなしのLLMによる回答の生成にかかった時間。 |
| rag.execution_time | RAGの回答の生成にかかった時間。 |
| llm.answer | RAGなしのLLMによる回答。 |
| rag.answer | RAGの回答。 |
| ground_truth | 理想の回答。 |
| llm.response_relevancy | RAGなしのLLMによる回答に対するResponse Relevancy。 |
| rag.context_precision | RAGの回答に対するContext Precision。 |
| rag.context_recall | RAGの回答に対するContext Recall。 |
| rag.context_entities_recall | RAGの回答に対するContext Entities Recall。 |
| rag.noise_sensitivity | RAGの回答に対するNoise Sensitivity。 |
| rag.response_relevancy | RAGの回答に対するResponse Relevancy。 |
| rag.faithfulness | RAGの回答に対するFaithfulness。 |

## summary.xlsx

### 目的
全てのRAGの評価結果の要約の保存。

### 保存ディレクトリ
`<project_root>/outputs/`

### 作成元
- `<project_root>/python/external/gemini/evaluate_gemini_{gemini_version}.py`
- `<project_root>/python/external/ollama/evaluate_gemma3_{model_size}b.py`
- `<project_root>/python/external/ollama/evaluate_gpt-oss_{model_size}b.py`

### 使用先
`<project_root>/python/tools/visualize.py`

#### ファイルの構造
| カラム名 | 説明 |
|------|-----------|
| llm | RAGで使用したLLMの名前。 |
| embedding_model | RAGで使用した埋め込みモデルの名前。 |
| eval_n | 検証用データの件数 |
| hardware | 使用したhardwareの情報を格納。（例）CUDA \| NVIDIA RTX 6000 Ada Generation (47GB) \| x86_64 (8 cores) \| RAM: 124GB |
| llm.total_execution_time | 全サンプルに対するLLM単体の回答の生成にかかった合計時間。hh:mm形式で表記する。 |
| rag.total_execution_time | 全サンプルに対するRAGの回答の生成にかかった合計時間。hh:mm形式で表記する。 |
| llm.avg_response_relevancy | RAGなしのLLMによる回答に対するResponse Relevancyの平均スコア。 |
| rag.avg_context_precision | RAGの回答に対するContext Precisionの平均スコア。 |
| rag.avg_context_recall | RAGの回答に対するContext Recallの平均スコア。 |
| rag.avg_context_entities_recall | RAGの回答に対するContext Entities Recallの平均スコア。 |
| rag.avg_noise_sensitivity | RAGの回答に対するNoise Sensitivityの平均スコア。 |
| rag.avg_response_relevancy | RAGの回答に対するResponse Relevancyの平均スコア。 |
| rag.avg_faithfulness | RAGの回答に対するFaithfulnessの平均スコア。 |
