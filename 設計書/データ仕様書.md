## results_{model_name}.xslx
### 目的
モデルごとの性能評価のログの保存。

### 保存ディレクトリ
outputs/external/gemini/

### 作成元
evaluate_{model_name}.py

### 使用先
visualize.py

### 構造

| カラム名 | 説明 |
|------|-----------|
| question | 質問文。 |
| context | RAGによって検索された文脈。 |
| llm.execution_time | RAGなしのLLMによる回答の生成にかかった時間。 |
| rag.execution_time | RAGの回答の生成にかかった時間。 |
| llm.answer | RAGなしのLLMによる回答。 |
| rag.answer | RAGの回答。 |
| ground_truth | 理想の回答。 |
| llm.response_relevancy | RAGなしのLLMによる回答に対するResponse Relevancy。 |
| rag.context_precision | RAGの回答に対するContext Precision。 |
| rag.context_recall | RAGの回答に対するContext Recall。 |
| rag.context_entities_recall | RAGの回答に対するContext Entities Recall。 |
| rag.noise_sensitivity | RAGの回答に対するNoise Sensitivity。 |
| rag.response_relevancy | RAGの回答に対するResponse Relevancy。 |
| rag.faithfulness | RAGの回答に対するFaithfulness。 |

| rag.context_recall | RAGの回答に対するContext Recallの平均スコア。 |

| rag.noise_sensitivity | RAGの回答に対するNoise Sensitivityの平均スコア。 |
